# IO_List — Master Slot-Configured I/O Workbooks & Tag Databases

This directory contains the primary master slot-configured I/O Excel workbooks and project tag databases for the **Ingredion Kalasin Spray Dryer Plant**.

---

## 📁 Workbook Inventory

* **`IO_List-By_SlotConfig.xlsx`**: Master slot-configured I/O database mapping ControlLogix Chassis C1 through C8 to field instrument tags, wire numbers, and terminal points.
* **`IO_List-By_SlotConfig-r02.xlsx`**: Revision 2 updated master slot-configured I/O workbook.
* **`IO_List-By_SlotConfig_rev02.xlsx`**: Engineering baseline revision 2 slot configuration workbook.
* **`IO_List_xDev-R01_Report.xlsx`**: Revision R01 generated I/O allocation report.
* **`IO_List_xDev-R02.xlsx`**: Revision R02 updated I/O allocation database.

---

## ⚙️ Purpose & Engineering Use Case

These workbooks are consumed by the automated CAD and PDF report generation tools in `04_Automation_Scripts` to produce single-slot DXF schematics, printable PDF reports, and SCADA tag databases.
