# 261005-IO_Config — Junction Panel & Remote I/O Configurations

This directory contains configuration reports, summary matrices, and Python allocation scripts for junction panels P1–P4 and the RIO-200 Remote I/O Skid for the **Ingredion Kalasin Spray Dryer Plant** (Date Baseline: October 5, 2026).

---

## 📁 File Inventory

* ⚙️ **`build_junction_io_panel_report.py`**: Python script processing junction box data and generating panel allocation workbooks.
* 📊 **`Junction_IO_List_Panel_P1_P4_Allocation_Report.xlsx`**: Detailed terminal allocation report for Marshaling Panels P1, P2, P3, and P4.
* 📊 **`Junction_to_Panel_P1_P4_Summary_Matrix.xlsx`**: High-level cross-reference matrix connecting field Junction Boxes to Marshaling Panels P1–P4.
* 📊 **`RIO-200_Remote_IO_Report.xlsx`**: Dedicated hardware allocation report for the RIO-200 Remote I/O Skid.

---

## 🛠️ System Scope

1. **Panels P1–P4**: Marshaling panel enclosures distributing field instrument signals to ControlLogix I/O modules.
2. **RIO-200 Skid**: EtherNet/IP Remote I/O drop serving Slurry Preparation & Chemical Dosing skids.
