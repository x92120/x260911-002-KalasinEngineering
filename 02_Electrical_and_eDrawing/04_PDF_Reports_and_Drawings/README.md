# 04_PDF_Reports_and_Drawings — Print-Ready PDF Engineering Deliverables

This directory contains print-ready, vectorized PDF drawing packages, master engineering sets, junction box schedules, MCC layout plans, and cable schedules for the **Ingredion Kalasin Spray Dryer Plant**.

---

## 📑 Master Engineering PDF Deliverables

| PDF Document Filename | Pages | Description / Scope |
| :--- | :---: | :--- |
| **`KALASIN_JET_COOKER_MASTER_ENGINEERING_DRAWINGS_COMPLETE.pdf`** | 82 | Master consolidated engineering drawing package for Jet Cooker System |
| **`Jet_Cooker_PLC_IO_Wiring_Drawings_Complete.pdf`** | 40 | Complete 40-sheet terminal wiring diagram set for Chassis C1–C5 |
| **`MCC_Panel_Layout_Mounting_Plan_M1_M2_M3_M4.pdf`** | 7 | General arrangement, internal layout, elevation, and BOM for MCC Panels M1–M4 |
| **`Cable_Schedule_MCC_to_Junction_Boxes.pdf`** | 8 | Master cable routing schedule from MCC room to plant Junction Boxes |
| **`Instrument_Installation_Hookup_and_Wiring_Templates.pdf`** | 25 | Field instrument installation hookup diagrams and wiring typicals |
| **`IO_List_All_Junction_Boxes_Master_Report.pdf`** | 82 | Complete terminal allocation report for all 16 field junction enclosures |
| **`Destination_IO_List_Master_Report.pdf`** | 82 | Destination-organized I/O schedule (JB-401, JB-402, JB-601–618, MCC) |
| **`Chassis_and_Slot_IO_Source_Destination_Report.pdf`** | 99 | Chassis & slot source-to-destination vector schedule (78 Slots, 1,210 Points) |

---

## 📁 Individual PDF Folders

* **`Chassis_Slots_PDF/`**: Per-chassis slot wiring PDF sheets for Chassis C1 to C7.
* **`Junction_Box_PDF/`**: Individual terminal schedule PDF reports for each Junction Box (JB-401, JB-402, JB-601–618, IS-JB-603–618).
