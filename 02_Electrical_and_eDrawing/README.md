## 📁 Module Directory Overview

This module houses all original vendor DWG schematics, exported ePlan packages, DXF/SVG CAD exports, print-ready PDF engineering drawing sets, instrument vendor documentation, SCADA demo assets, and control strategy presentations.

```text
02_Electrical_and_eDrawing/
├── 01_Source_Drawings_DWG/          # Original vendor AutoCAD DWG schematics & wiring layouts
├── 02_ePlan_Exports/                # Exported ePlan project packages & electrical schematics
├── 03_CAD_Exports_DXF_SVG/          # 154 vectorized DXF & SVG component & panel sheets
├── 04_PDF_Reports_and_Drawings/     # 145 engineering PDF drawings, JB reports & cable schedules
├── 05_Instrument_Manuals/           # 22 vendor instrument manuals & IS Barrier datasheets
├── 06_SCADA_Demo/                   # SCADA HMI demo screens, process trend slides & HTML viewers
└── 07_Presentations_and_Overviews/  # PID loop control specification slides & architecture overviews
```
