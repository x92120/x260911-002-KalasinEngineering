## 📂 Folder Overview

This module houses all original source drawings, ePlan electrical schematics, CAD exports (DXF/SVG), engineering PDF deliverables, instrument manuals, and SCADA demo assets.

```text
02_Electrical_and_eDrawing/

├── 02_ePlan_Exports/                # Exported ePlan project packages & electrical schematics
├── 03_CAD_Exports_DXF_SVG/          # 154 vectorized DXF & SVG component & panel sheets
├── 04_PDF_Reports_and_Drawings/     # 145 engineering PDF drawings, JB reports & cable schedules

```
