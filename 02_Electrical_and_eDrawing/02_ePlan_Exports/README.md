# 02_ePlan_Exports — Exported ePlan Engineering Packages

This directory contains exported ePlan Electric P8 project packages, layouts, PLC tag databases, and terminal summaries for the **Ingredion Kalasin Spray Dryer Plant**.

---

## 📂 Subdirectories & File Inventory

### 1. ePlan Project Directories
* **`SPRINT 18K SPRAY DRYER/`**: Complete ePlan Electric P8 project data folder for the Spray Dryer Process control panel.
* **`SPRINT 18K SPRAY DRYER ELECTRICAL/`**: Complete ePlan Electric P8 project data folder for Plant Electrical Distribution & Power.

### 2. Exported Files & Tag Databases
* **`Layout.dxf`**: Panel layout export in AutoCAD DXF format.
* **`PLC_Terminal_Summary_Option1_C1_C2.pdf`**: Consolidated PLC terminal summary report for Chassis C1 & C2.
* **`Tags list PLC.xlsx`**: Master PLC Tag database exported from ePlan.
* **`Tags list PLC-r02.xlsx`**: Revision 2 updated PLC Tag database.
* **`Tags list PLC-Option1-DirectSlot-C1-C8.xlsx`**: Direct slot-based tag database mapping for Chassis C1 to C8.
