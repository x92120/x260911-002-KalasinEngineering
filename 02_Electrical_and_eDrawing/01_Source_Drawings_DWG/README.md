# 01_Source_Drawings_DWG — Original Vendor AutoCAD DWG Drawings

This directory contains the original vendor AutoCAD `.dwg` schematics, panel layouts, and wiring diagrams for the **Ingredion Kalasin Spray Dryer Plant** (Ref: `R5THS00138`).

## 📌 Usage & Engineering Context

These drawings serve as the baseline source drawings provided by the vendor. They were used to extract wire numbers, device tags, terminal assignments, and panel layouts that feed into the automated DXF generation tools located in `04_Automation_Scripts`.
